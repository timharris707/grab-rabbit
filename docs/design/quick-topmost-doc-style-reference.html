Grab Rabbit · Issue 57 · Throwaway prototype

Make starting and stopping Quick Topmost impossible to miss.

Three interface directions, each played out in the same mock desktop so they can be compared on one variable: what you see. Press the hotkey to run a recording start to finish. The simplicity bar is TapRecord — one clear surface, no settings in your face, nothing to hunt for.

FAILURE 1

Silent start

The hotkey started a recording with nothing on screen. The hotkey got pressed again and again; the recording was already running and had reached 12 GB before anyone noticed.

FAILURE 2

Nowhere to look

With the app launched headless there was no menu bar icon and no window — no way to check status or stop the recording.

FAILURE 3

Two names, one feature

Settings groups it as “Quick Topmost Window” while the hotkey row reads “Record Topmost Window.” Every variant here uses one name: Quick Topmost.
